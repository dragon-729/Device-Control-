# Security Policy

## Supported versions
Only the latest release receives security fixes.

## Reporting a vulnerability
Please **do not** open a public issue. Use GitHub's private vulnerability reporting
(<https://github.com/hgcheat094-max/DroidLink/security/advisories/new>) or message the maintainer on Telegram:
[@YogeshBhai729](https://t.me/YogeshBhai729) (ask for a private channel before sharing details).

Include: affected version, steps to reproduce, impact, and a suggested fix if you have one.
You can expect an acknowledgement within a few days. Please allow time for a fix before public disclosure.

## Scope
In scope: the Android app, the relay server, the CI/release workflows. Out of scope: attacks that require a rooted or
already-compromised device, social-engineering of the device owner, vulnerabilities in third-party dependencies
that are already publicly tracked (report those upstream).

## Misuse
DroidLink is for devices you own or are authorised to manage. Reports of the project being deliberately modified for
stalking, covert surveillance or unauthorised access will be treated as abuse; we will not support such forks.

Details of the security design: [docs/SECURITY.md](docs/SECURITY.md).
